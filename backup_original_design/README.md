# RANGRITICO — Original Design Backup Archive

This directory preserves the complete original codebase of the RANGRITICO Art Atelier website prior to the enhancements made on September 18, 2026.

## Archived Files:
- `index.html`: Original homepage and atelier shop
- `portfolio.html`: Original horizontal swaying frames gallery
- `about.html`: Original bio, academic research & CV page
- `styles.css`: Original stylesheets
- `script.js`: Original client interactivity and presentation scripts
- `gsap-animations.js`: Original GSAP scroll and swaying animations

## To Preview or Restore:
- To preview: Open `backup_original_design/index.html` or `backup_original_design/portfolio.html` directly in any web browser.
- To restore: Copy all files from this directory back into the project root directory:
  ```bash
  cp backup_original_design/* .
  ```
